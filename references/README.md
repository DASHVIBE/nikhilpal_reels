# references/ 📚

Is folder se Claude ko pata chalta hai ki channel par kaisi kahaniyan chahiye.

## stories/: aapki apni kahaniyan (optional)
| Folder | Kya daalein | Video kaisi banegi |
|---|---|---|
| `stories/devotional/` | Kisi bhakt ki katha ya Mahabharat ka koi raaz | Bhakt Katha, 2-3 parts |
| `stories/paheli/` | Chori, jhootha daava ya bantwara wala case | Chatur Ka Nyay, Part 1 case, Part 2 faisla |

- Har kahani ek `.txt` file me. Hindi ya Hinglish, chhoti ya lambi, sab chalega.
- Naam number se shuru karein (`01_pundalik.txt`, `02_vidur.txt`). Isi kram me use hongi, har kahani sirf ek baar.
- Folder khaali ho to Claude khud web se asli katha / lok kahani dhoondh kar likhta hai.

## style.md: channel ka andaaz
Har script likhne se pehle Claude ise padhta hai. Tone, kya chahiye, kya nahi: yahan likh dijiye.

## avoid.md: ye kahaniyan mat banao
Jo kahaniyan kisi bhi wajah se nahi chahiye, unki ek line yahan likh dijiye.

## videos/: pasand ki videos (sirf laptop par)
Koi video ka design pasand aaye to `.mp4` yahan rakhiye aur Claude Code ko bataiye. Ye GitHub par upload nahi hoti.
